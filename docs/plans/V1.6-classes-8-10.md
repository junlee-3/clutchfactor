## Rule 1 — `H1_DESPERATION_PEEK` → class 8 (new file `families/h1.rs`, detector `H1ManCount`)

Spec: "`man_advantage <= -1`, player initiated, and the clock did not demand it". Target case: 3v4, 40 s left, nothing forcing contact, walked into the open looking for the equaliser.

Fire for a tracked death when ALL hold (any `None` → silent):
1. Killer is an enemy (`side_of` known and opposite; copy `enemy_of` from h2.rs), killer state exists and is alive at the kill tick, victim state exists.
2. **Man disadvantage.** Add to `AnalysisContext`: `pub fn alive_counts_at(&self, round: u32, tick: i32) -> Option<(usize, usize)>` = (CT alive, T alive) by kill-event replay over the round's rosters (`Round.ct_steamids`/`t_steamids`, kills with `k.tick <= tick`), and `pub fn man_advantage(&self, steamid: u64, round: u32, tick: i32) -> Option<i32>` = mine − theirs from the tracked side. Evaluate at `kill.tick - 1` so the death itself is not counted (same convention as `play_ledger::man_context`). Require `man_advantage <= h1.disadvantage_max` (default −1). Refactor `play_ledger` to call the new context helper (keep its output byte-identical — the goldens will tell you).
3. **Not last alive**: my alive count at `kill.tick - 1` ≥ 2 (a 1vN is a clutch, judged elsewhere).
4. **Player initiated (kinematic proxy).** Over the window `[kill.tick − seconds(h1.approach_window_s), kill.tick]` (default 2.0 s), stepping samples every `seconds(0.25)`: `victim_closed_u` = distance(victim, killer) at window start − at death, using `AnalysisContext::dist` with `general.z_weight`. Require `victim_closed_u >= h1.approach_min_u` (default 150) AND the victim's own path length over the window ≥ `h1.approach_min_u` AND `killer_moved_u <= victim_moved_u` (the killer moved less than the victim — if the killer was the one pushing, the victim was defending → silent; this is the spec's "enemy already pushing you" suppression). If either player has no sample at the window start → silent.
5. **The clock did not demand it.** Derive `elapsed_s = (kill.tick − freeze_end_tick) / tickrate` (use `Round.freeze_end_tick`, else `start_tick`). Add config `h1.round_length_s` (default 115.0) and `h1.bomb_timer_s` (default 40.0). Bomb planted state from `ctx.data().bomb_events` (see the "planted" idiom in `context.rs:321-330`). Suppress when: CT side AND planted AND `bomb_timer_s − (kill.tick − plant_tick)/tickrate < h1.ct_retake_forced_s` (default 12.0); T side AND not planted AND `round_length_s − elapsed_s < h1.t_forced_s` (default 20.0); any derived remaining time < 0 (data oddity → silent).
6. **Not traded**: killer not killed within `h1.traded_within_s` (default 2.0) after the death (`killed_in` from h2.rs — make it `pub(crate)` if it isn't).

Flag: `tick = kill.tick`, `steamid = tracked`, `confidence = 0.6` (kinematic proxy — spec caps approximations at 0.6–0.7), `severity = cfg.severity.h1_desperation_peek` (default 0.6), `details` = `{ "man_context": "3v4", "my_alive": 3, "their_alive": 4, "closed_u": 312.0, "killer_moved_u": 40.0, "seconds_left": 41.2, "place": me.place, "killer": "<steamid string>" }`, evidence via `evidence_around(ctx, round, kill.tick, &[tracked, killer])`.

Insight (match-level, `Category::Deaths`) when ≥ 2 flags, same shape as h2/h4 (`INSIGHT_MIN_OCCURRENCES = 2`, cap 8 evidence refs); `title_data = { "count", "rule", "man_contexts": [...] }`.

Tests (write first, one per clause): fires on the target case; silent when advantage is even or positive; silent when last alive; silent when the victim did not close ≥ 150 u; silent when the killer moved more than the victim; silent CT+planted+<12 s; silent T+no plant+<20 s; silent when traded within 2 s; silent when killer side unknown / teamkill; insight only at ≥ 2. Plus `classify.rs` tests mirroring `push_without_info_classifies_as_11_below_crossfire`: class 8 sources when alone; class 6 (isolated) outranks it and it lands in `secondary_tags`; class 8 outranks 9/10/11.

## Rule 2 — `H4_WIDE_PEEK_HELD_ANGLE` → class 10 (add to `families/h4.rs`, the id the spec's Tier 2 names)

Spec framing: "Whoever is further from the corner sees the other first" — we have no geometry, so the proxy is: the victim swung into an enemy who was holding still, engaged, and lost.

Fire for a tracked death when ALL hold (any `None` → silent):
1. Killer is an enemy, alive at the kill tick; victim state exists; the kill is not `thru_smoke` and `penetrated == 0` (those are class 5's — leave them).
2. Over `[kill.tick − seconds(h4.peek_window_s), kill.tick]` (default 1.5 s), stepping every `seconds(0.25)`: victim path length ≥ `h4.exposure_min_u` (default 120) AND killer path length ≤ `h4.holder_max_u` (default 60) AND distance(victim, killer) decreased over the window (the victim approached the holder).
3. **A duel happened**: the victim fired ≥ 1 shot in the window (`shots_by_in`) OR dealt damage to the killer in it (`hurts_dealt_in`). No engagement → silent (that death is class 5 or 13's to judge).
4. Distance at death ≥ `h4.wide_peek_min_dist_u` (default 150) — point-blank scrambles are not angle duels.

Flag: `confidence = 0.6`, `severity = cfg.severity.h4_wide_peek_held_angle` (default 0.5), `details` = `{ "exposed_u": 180.0, "killer_moved_u": 12.0, "distance": 640.0, "shots": 3, "place": me.place, "killer_place": killer.place, "killer": "<steamid string>" }`. Insight at ≥ 2 like the others.

Tests, one per clause, plus classify tests: class 10 sources alone; class 9 (crossfire) and class 8 outrank it; it outranks 11.
