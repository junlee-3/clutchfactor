# V1.2 Round-by-Round Coaching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship issue #9 complete — a coach rail beside the 2D replay surfacing a small number of high-impact rounds, every claim carried by a number and jumpable to the tape.

**Architecture:** A pure `cf-analysis::round_review` engine replays each round's event stream (kills + bomb) against the win-probability table to produce signed impact, a verdict, and structured moments; results persist in a new `round_review` table (computed at import, lazily backfilled for old matches from DB rows — the `run_positioning` post-pass precedent). Narration to strings happens at serve time in a new `cf-narrator::rail` module (structured facts stay stored — V1.3's grounding contract feeds from them). The frontend adds a 330px coach rail column, colorless attention dots on the round strip, moment-synced highlighting off `displayTick`, and canvas overlays (focus dimming exists; the dashed teammate line + solid killer line are new).

**Tech Stack:** Rust (serde_json, rusqlite), React/TS, vitest pure modules, existing `winprob`/`phase_at`/`callouts` modules.

**Spec:** GitHub issue #9 (THE spec — its decisions bind; `gh issue view 9`). Charter PROMPT-V1.md §3 (definition of perfect). Design decisions from the 2026-08-22 brainstorm are inlined below and recorded as ADR-0008 (Task 2). Design system: `docs/design/design-system.md` (§5 dashed grammar names this feature's two new surfaces).

## Global Constraints

- **Issue #9's decisions are binding:** threshold+cap selection (never top-N); win-prob impact (man-count heuristic forbidden); five verdicts with two hard rules (`Cost you` = measured position change, never fault language; `Not on you` = positively established by a rule, never absence-of-flags); the number IS the finding; flag joins on `(match_id, round, tick)`; narration NOT in `templates.rs`; no economy/buy coaching anywhere; at least one `Won it` surfaced when one qualifies; playback never auto-pauses; rail text generated from the round's own event stream, never fixed templates with counts substituted; attention dots spend no color channel.
- **Silence bias:** `winprob::p_ct_win` returns `None` for unobserved cells — an event with an unobserved before/after state contributes NOTHING to impact (skip, never guess). All thresholds in `DetectorConfig::rbr` in probability units/counts, documented.
- Rule ids are load-bearing strings; `RuleFlag.rule_id` is `&'static str` — own it via `.to_string()` (the `DeathClassRow.class_source` precedent).
- Verdict "traded" uses `cfg.trade.commit_window_s` (2.0 s) — the SAME window H2 uses to decide a death was traded (`h2.rs:144-147`); never `window_s`.
- Design system §5: dashed chalk `[4,3]` = evidence (the teammate line, the rail's active-moment left stripe); solid killer line uses `--loss` (threat semantics, the bomb precedent); nothing decorative may be dashed. CT/T hues only for side identity.
- Frontend: pure logic in `src/lib/` or `src/replay/` `.test.ts` modules (no RTL/jsdom, no new deps); `seek()` for moment jumps, NEVER a `?tick=` URL write inside a round (remount trap — `RoundPlayer` keys on `evidence.tick`); TanStack key `["round_review", matchId]` with `staleTime: Infinity`; ipc MIRROR CHECKLIST updated in the same commit as any DTO.

**The model (copy into ADR-0008 and the module header):**
1. **State replay per round:** start `(ct = round.ct.len(), t = round.t.len(), planted = false)`. Events in tick order within `[start_tick, officially_ended_tick.unwrap_or(end_tick)]`: kills with that `round` number (skip `round == 0`), plus bomb events in the span. Kill → decrement the victim's side (roster lookup; victim on neither roster → skip, silence). Plant → `planted = true`. Defuse → CT-side P becomes 1.0 (round decided). Explode → CT-side P becomes 0.0.
2. **ΔP per event** = `P_after − P_before` where `P` = `p_ct_win(...)` if tracked ∈ round.ct else `1 − p_ct_win(...)`; either side `None` → event unobserved → `delta_p = None`, contributes nothing.
3. **impact** = Σ `delta_p` over PLAYER-ATTRIBUTED events: `kill.attacker == Some(tracked)`, `kill.victim == tracked`, `bomb.player == Some(tracked)` (plant/defuse).
4. **pivotal_tick** = tick of max `|delta_p|` over ALL scored events (the round's turning point, not necessarily the player's).
5. **Selection:** candidates = rounds with `|impact| ≥ attention_threshold_p`, sorted by `|impact|` desc, take `max_rounds`. **Won-it guarantee:** if a candidate with `verdict == WonIt` was cut by the cap AND the selection contains a non-WonIt, replace the lowest-|impact| non-WonIt with the highest-|impact| excluded WonIt.
6. **Attention:** `selected && |impact| ≥ pivotal_threshold_p` → Bright; `selected` → Dim; else None (a capped-out round shows no dot — no dot without rail content).
7. **Verdict precedence (the load-bearing order — `NotOnYou` MUST precede `CostYou`):**
   - `WonIt`: `impact ≥ attention_threshold_p && header.won`
   - `NotOnYou`: any flag with `steamid == tracked`, this round, `rule_id ∈ cfg.rbr.exculpatory_rules`
   - `Traded`: tracked died this round AND the killer appears as a victim within `commit_window_s` after the death AND `impact > −pivotal_threshold_p`
   - `CostYou`: `impact ≤ −attention_threshold_p`
   - `Quiet`: otherwise
8. **Moments (selected rounds only; unselected rounds get `moments: vec![]`):** one per tracked kill / tracked death / tracked plant / tracked defuse (with `delta_p`), plus one `"flag"` moment per tracked-player flag in the round whose tick doesn't already have a moment (dedup by tick: a death moment absorbs its death-anchored flags — merge each such flag's `details` into the death moment's `facts` and set `rule_id` to the highest-severity fired rule). Death facts add `"killer"`, `"traded"`, `"round_end_delta_s"` (`(round end − death tick)/tickrate`, 1 decimal). Tick order, cap `max_moments` (keep earliest N — the story reads forward).
