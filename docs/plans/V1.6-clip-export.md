## What ships

One button on the Replay transport row — **Export clip** — and one hotkey (`E`). Click it and the app records the 2D replay around what you are looking at, at 1× speed, and writes a video file to the user's Videos folder (`~/Movies/ClutchFactor/` on macOS, `~/Videos/ClutchFactor/` on Windows). No dialog. A toast reports the saved path. That is the whole feature. Nothing else changes in the replay.

Why no save dialog: one click → file, like a screenshot. The folder is fixed and discoverable; the toast names the path.

## Clip window (pure logic, `src/replay/clip.ts`, TDD'd in `clip.test.ts`)

```ts
export interface ClipWindow { startTick: number; endTick: number }
/** −5 s/+2 s around an active tracked-death moment (reuse `overlayWindow` from rail.ts);
 *  otherwise −6 s/+3 s around the playhead. Always clamped to the round `spec`
 *  (TimelineSpec). Never shorter than 1 s: if clamping leaves < 1 s, extend the
 *  other side inside the spec. */
export function clipWindow(spec: TimelineSpec, playheadTick: number, momentTick: number | null, tickrate: number): ClipWindow
/** e.g. "mirage-r12-0m34s.mp4" — map without the de_ prefix, round, clock of startTick
 *  relative to spec.startTick (fmtClock in timeline.ts is the clock formatter — check its
 *  output shape and keep the filename filesystem-safe: [a-z0-9-]+ and one dot). */
export function clipFileName(map: string, round: number, spec: TimelineSpec, win: ClipWindow, tickrate: number, ext: string): string
/** First supported of: video/mp4;codecs=avc1 → video/webm;codecs=vp9 → video/webm;codecs=vp8 → video/webm.
 *  Returns { mime, ext } ("mp4" | "webm") or null when nothing is supported (then the button is disabled with title "Recording not supported in this WebView"). */
export function pickMimeType(isTypeSupported: (t: string) => boolean): { mime: string; ext: "mp4" | "webm" } | null
/** Seconds recorded / total, for the button label "Recording 3.2 s / 7.0 s". */
export function clipProgress(win: ClipWindow, tick: number, tickrate: number): { done: number; total: number }
```

## Recorder (thin DOM module, `src/replay/recorder.ts`, no unit tests — keep it small)

```ts
export interface ClipRecorder { stop(): Promise<Blob>; cancel(): void }
export function startClipRecorder(source: HTMLCanvasElement, mime: string, label: string): ClipRecorder
```
- Create an offscreen `<canvas>` 1024×1024 (dpr 1) — the on-screen canvas is 1024·dpr (up to 2048²) and we want a stable, cheaper output. Each `requestAnimationFrame` while recording: `ctx.drawImage(source, 0, 0, 1024, 1024)` then paint `label` (e.g. "Mirage · R12 · misosoupy3") in a translucent band along the bottom edge using the design tokens via `src/lib/theme.ts` (`getToken`), 13 px system font. Solid, not dashed (design-system §5: nothing decorative is dashed).
- `export.captureStream(30)` → `new MediaRecorder(stream, { mimeType: mime, videoBitsPerSecond: 4_000_000 })`, `ondataavailable` collects chunks; `stop()` resolves with the Blob after `onstop`; `cancel()` stops without resolving data.
- StrictMode double-effects: the recorder must only be created from an explicit click handler, never from an effect.

## Screen wiring (`src/screens/Replay.tsx`, `src/replay/ReplayCanvas.tsx`)

- `ReplayCanvas` gets an optional prop `onCanvas?: (c: HTMLCanvasElement | null) => void`, called once from the mount effect (and with null on unmount). `RoundPlayer` stores it in a ref.
- New state: `recording: { win: ClipWindow; recorder: ClipRecorder; fileName: string } | null` (ref + mirrored state for the label).
- Click / `E`: compute `win = clipWindow(spec, tickRef.current, annotationMoment?.tick ?? null, d.tickrate)`; `seek(win.startTick)`; `setSpeed(1)`; start the recorder; `setPlaying(true)`.
- In `onFrame` (the existing rAF callback at Replay.tsx ~527): when recording and `tickRef.current >= win.endTick` → `setPlaying(false)`, `await recorder.stop()`, save (below), clear state. Also stop if the round auto-pauses at `spec.endTick`.
- While recording: the button reads `Recording 3.2 s / 7.0 s` (text only, `aria-live="polite"`, no pulsing/red — design-system §2/§4), Play/Segmented/Callouts/Scrubber are `disabled`, the keyboard handler ignores Space/arrows/1-3 and `Escape` cancels (recorder.cancel(), seek back to where the user was, toast "Clip cancelled").
- Button: `<Button variant="secondary" size="sm" onClick={exportClip} disabled={!mime}>Export clip</Button>` placed right after the Callouts button. Must still fit at 1200×760 (design-system §7) — check `.rpl-transport` in `src/styles/screens.css` and shorten labels before adding width.
- Saving: `const bytes = new Uint8Array(await blob.arrayBuffer()); const path = await saveClip(bytes, fileName);` then `toast.push("status", \`Clip saved · ${path}\`)`; on error `toast.push("error", errorMessage(e))` (`src/lib/errors.ts`).
